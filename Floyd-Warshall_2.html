Floyd-Warshall 算法详解

多源最短路径 · 动态规划 · 时间复杂度 O(n³)

一、这个算法要解决什么问题

前面学的 Dijkstra 算法，一次只能求出一个起点到其他所有点的最短距离，这叫单源最短路。如果题目要求任意两个顶点之间的最短路径长度，就要对每个顶点都跑一遍 Dijkstra，复杂度是 O(n·(n+m)log n)，当 n 不大但边很稠密时并不划算。

Floyd-Warshall 算法（通常简称 Floyd）一次就能求出所有点对之间的最短距离，也就是多源最短路（更准确说是"全源最短路"）。它的代码极短，只有三重循环，而且能处理负权边（只要没有负权回路）。代价是复杂度固定为 O(n³)，所以它只适合 n 比较小的情况，比如本题 n ≤ 100。

题目给出的是一张 n 个顶点、m 条边的无向连通带权图，边权为正，可能含有重边，要求输出一个 n×n 的矩阵，第 i 行第 j 列表示顶点 i 到顶点 j 的最短距离。

二、核心思想：一步一步"放开"中转点

Floyd 算法的出发点非常朴素：两点之间的最短路，要么是直达，要么是绕道经过某些点。如果我把"允许经过哪些点"这件事控制住，让允许的集合一点点变大，那么每一步都能得到一个确定的最短路，最后集合扩到全部顶点时，答案就出来了。

具体来说，我们给顶点从 1 到 n 编号，然后定义这样一个量：

f[k][i][j] = 从顶点 i 到顶点 j，且中途只允许经过编号在 {1, 2, …, k} 里的点作为中转点时，最短路径的长度

注意"中转点"的含义：路径的两个端点 i 和 j 不算中转点，中间踩过的点才算。当 k = 0 时，不允许任何中转点，那么 f[0][i][j] 就是 i 和 j 之间直接相连的那条边的权值（没有边就是无穷大，i 等于 j 时是 0）。

我们的目标是求出 f[n][i][j]，也就是允许所有点当中转点时的最短距离。

三、状态转移方程

现在考虑怎么从 f[k-1] 推出 f[k]。相比 f[k-1]，f[k] 只是多放开了一个中转点 k。那么从 i 到 j 的最短路（只允许经过 1..k）只有两种可能：

  1. 根本不经过 k。那么它其实只用了 1..k-1 这些中转点，长度就是 f[k-1][i][j]。
  2. 经过了 k。既然经过了 k，我们就可以把这条路径在 k 处切成两段：i → k 和 k → j。这两段各自都只用 1..k-1 里的点当中转点（因为 k 只在中间出现一次，否则就绕圈了），长度分别是 f[k-1][i][k] 和 f[k-1][k][j]，合起来就是 f[k-1][i][k] + f[k-1][k][j]。

两种情况取较小值，就得到转移方程：

f[k][i][j] = min( f[k-1][i][j] , f[k-1][i][k] + f[k-1][k][j] )

这个方程的边界条件是：

  • f[0][i][i] = 0（自己到自己距离为 0）
  • f[0][i][j] = 边 (i, j) 的权值（若 i ≠ j 且有边），否则为无穷大

四、为什么 k 必须放在最外层循环

这是本题最容易被写错的地方，文件里也专门强调过。

回看状态的定义：f[k][i][j] 的含义是"只允许编号不超过 k 的点当中转点"。这个定义本身就规定了计算的先后次序——你必须先把 k = 1 这一层全部算完，才能算 k = 2；先把 k = 2 全部算完，才能算 k = 3……也就是说，"允许的集合"必须按 1、2、3…… 的顺序一个一个地加进去。

而三重循环中，k 在最外层，恰好对应了"逐层扩展允许集合"这个过程。如果 k 被写在了内层，比如写成 i 在最外层、k 在中间、j 在最内层，那么在计算某一行时，dis[i][k] 和 dis[k][j] 这两项本身可能还没有在当前这一层被正确地算出来（它们可能依赖于后面才轮到的 i 值），于是 f 的分层假设被打破，就相当于在"半成品"的数据上做转移，最终结果可能不正确。

记住三重循环里，中间点 k 必须是最外层，i 和 j 的顺序可以互换，但 k 不能动。判断顺序对不对，只需看一句话：每次用 k 更新时，dis[i][k] 和 dis[k][j] 都必须是"只允许 1..k-1 当中转点"的结果。

五、为什么可以只用一个二维数组原地更新

理论上我们需要 f[0]、f[1]、…、f[n] 一共 n+1 个 n×n 的数组，空间太大。但实际上可以只用一个二维数组 dis[i][j]，边算边覆盖旧值。原因是这样的：

在第 k 层里，我们要用到 dis[i][k] 和 dis[k][j]。先看 dis[i][k] 这一项，把转移方程里 j 换成 k：

f[k][i][k] = min( f[k-1][i][k] , f[k-1][i][k] + f[k-1][k][k] )

而 f[k-1][k][k] = 0（自己到自己，最短距离就是 0），所以右边变成 min(f[k-1][i][k], f[k-1][i][k] + 0) = f[k-1][i][k]。也就是说，第 k 层的第 k 行和第 k 列，和第 k-1 层完全一样，在这一层里根本不会被改变。

既然 dis[i][k] 和 dis[k][j] 在整个第 k 层中都是稳定的，那么"先用它们去更新 dis[i][j]，更新后的 dis[i][j] 再被别人当参考"这种事情就不会发生，第 k 层的结果和第 k-1 层的结果可以共用同一块空间，直接覆盖写回即可。这就是二维数组原地更新的正确性依据。

注意上面这一步用到了 f[k-1][k][k] = 0 这个事实。如果图里有负权回路（绕一圈回来总权值是负数），那么 dis[k][k] 会变成负数，这个推理就不成立了，算法就会出错。这就是"Floyd 可以处理负权边，但不能有负权回路"的根本原因。

六、复杂度分析

  • 时间复杂度：O(n³)。三重循环分别枚举中间点 k、起点 i、终点 j，每一层都是 n 次，总计 n³ 次基本操作。本题 n ≤ 100，n³ = 10⁶，非常快。
  • 空间复杂度：O(n²)。只需要一个 n×n 的二维距离矩阵。本题 n ≤ 100，105×105 的 int 数组约 44KB，完全够用。

七、代码逐段讲解

1. 预处理：距离矩阵的初始化

const int N = 105;
const int INF = 0x3f3f3f3f;

int dis[N][N];

memset(dis, 0x3f, sizeof(dis));

for (int i = 1; i <= n; ++i) {
    dis[i][i] = 0;
}

这里有几个要点：

  • INF = 0x3f3f3f3f 的值是 1061109567，约 10⁹。这个值本身不会溢出 int（int 上限约 2.1×10⁹），而且两个 INF 相加是 2122219134，仍然小于 int 上限，不会溢出成负数。这是一个很常用的技巧。
  • memset(dis, 0x3f, sizeof(dis)) 会把每个 int 的四个字节都写成 0x3f，于是每个 int 的值正好就是 0x3f3f3f3f，也就是我们想要的 INF。
  • 对角线必须单独设成 0。因为自己到自己不走任何边，距离是 0，而不是无穷大。这一步如果漏了，后面的转移会全错（比如 dis[i][i] 会一直是 INF，最终输出一个巨大的数）。

2. 读入边，处理重边

for (int i = 1; i <= m; ++i) {
    int u, v, w;
    cin >> u >> v >> w;

    dis[u][v] = min(dis[u][v], w);
    dis[v][u] = min(dis[v][u], w);
}

因为是无向图，一条边 (u, v, w) 要同时写进 dis[u][v] 和 dis[v][u] 两个位置。题目说图中可能存在重边，也就是同一条边可能给出多次、权值不同，这时显然要保留较小的那个权值，所以用 min(dis[u][v], w) 而不是直接赋值。

3. 三重循环：核心部分

for (int k = 1; k <= n; ++k) {
    for (int i = 1; i <= n; ++i) {
        for (int j = 1; j <= n; ++j) {
            if (dis[i][k] == INF || dis[k][j] == INF) {
                continue;
            }

            dis[i][j] = min(dis[i][j],
                dis[i][k] + dis[k][j]);
        }
    }
}

这段代码就是转移方程的直接翻译：

  • 最外层 k 枚举中转点，从 1 到 n 逐个"放开"，这是算法正确性的关键，不能换位置。
  • 中间 i 枚举起点，最内层 j 枚举终点，对每一对 (i, j) 都尝试用 k 来缩短距离。
  • if (dis[i][k] == INF || dis[k][j] == INF) continue; 这一句是防止无穷大参与加法。如果 i 到 k 不可达，或者 k 到 j 不可达，那么"经过 k"这条路根本不存在，直接跳过。虽然前面说过两个 INF 相加不会溢出成负数，但那种情况算出来是一个很大的数，虽然没有实际危害，但语义上不清晰，而且如果 INF 取的是 LLONG_MAX / 4 这类值，相加就真的可能溢出了。所以这个判断是必要的良好习惯。

4. 输出答案

for (int i = 1; i <= n; ++i) {
    for (int j = 1; j <= n; ++j) {
        cout << dis[i][j] << (j == n ? '\n' : ' ');
    }
}

按行输出 n×n 的矩阵，行内用空格分隔，行末换行。题目保证图是连通的，所以最终所有 dis[i][j] 都是有限的真实距离，不会出现 INF。

八、完整代码（C++14 标准，可直接提交）

#include <bits/stdc++.h>
using namespace std;

const int N = 105;
const int INF = 0x3f3f3f3f;

int dis[N][N];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;

    memset(dis, 0x3f, sizeof(dis));

    for (int i = 1; i <= n; ++i) {
        dis[i][i] = 0;
    }

    for (int i = 1; i <= m; ++i) {
        int u, v, w;
        cin >> u >> v >> w;

        dis[u][v] = min(dis[u][v], w);
        dis[v][u] = min(dis[v][u], w);
    }

    for (int k = 1; k <= n; ++k) {
        for (int i = 1; i <= n; ++i) {
            for (int j = 1; j <= n; ++j) {
                if (dis[i][k] == INF || dis[k][j] == INF) {
                    continue;
                }

                dis[i][j] = min(dis[i][j],
                    dis[i][k] + dis[k][j]);
            }
        }
    }

    for (int i = 1; i <= n; ++i) {
        for (int j = 1; j <= n; ++j) {
            cout << dis[i][j] << (j == n ? '\n' : ' ');
        }
    }

    return 0;
}

整份代码只用了 C++98 就有的语法（数组、memset、min、cin/cout、标准 for 循环），在 NOIP 标准的 g++14 环境下没有任何兼容性问题，可以直接编译运行。

十、本题的坑点

坑点 1三重循环的顺序不能随意调整，中间点 k 必须放在最外层。这是由状态定义"只允许前 k 个点当中转点"决定的，k 在内层会破坏动态规划的分层顺序，导致答案错误。这是本题最容易失分的地方。
坑点 2图中可能存在重边，初始化时必须取较小边权。读入无向边时，要用 dis[u][v] = min(dis[u][v], w) 而不是直接 dis[u][v] = w，否则后读入的较大权值会覆盖掉前面较小的权值。
坑点 3要正确设置 dis[i][i] = 0。如果用 memset 把整个矩阵都设成 INF，忘记把对角线改回 0，那么所有"自己到自己"的距离都会是无穷大，转移过程中也会出问题，最终输出全错。
坑点 4无穷大参与加法要小心。代码里用 if (dis[i][k] == INF || dis[k][j] == INF) continue; 提前跳过不可达的情况，既避免了语义上的混淆，也避免了在换成 long long 大常量时可能出现的溢出。

十一、小结

  • Floyd 的本质是动态规划：状态 f[k][i][j] 表示只允许编号 1..k 的点当中转点时，i 到 j 的最短距离。
  • 转移方程是 f[k][i][j] = min(f[k-1][i][j], f[k-1][i][k] + f[k-1][k][j])，含义是"不经过 k"和"经过 k"两种情况取较小值。
  • 因为第 k 层的第 k 行、第 k 列与第 k-1 层完全相同（利用了 dis[k][k] = 0），所以可以压缩成一个二维数组原地更新。
  • k 必须是最外层循环，这一点由状态定义决定，不能改动。
  • 时间复杂度 O(n³)，空间复杂度 O(n²)，适合 n ≤ 100 左右的稠密图全源最短路问题。
  • 可以处理负权边，但不能有负权回路。
