1. 多项式乘法为什么慢

多项式在信息学里非常常见，它可以表示成系数和自变量的组合。一个 n 项多项式通常写成

A(x) = a0 + a1x + a2x2 + ... + an-1xn-1

其中 a0, a1, ..., an-1 是系数。两个多项式相乘，结果的第 k 次项系数来自所有下标相加等于 k 的系数对：

ck = a0bk + a1bk-1 + ... + akb0 = Σi aibk-i

如果直接按这个式子计算，每个结果系数都要检查许多对系数，两个长度分别为 n 和 m 的多项式相乘，最坏要做 n×m 次乘法。当 n=m=100000 时，n×m 是一百亿，普通计算机很难在竞赛时限内完成。

先看一个很小的例子，计算 A(x)=1+2x+3x2 与 B(x)=4+5x 的乘积：

结果项系数计算系数
x01×44
x11×5 + 2×413
x22×5 + 3×422
x33×515

所以 (1+2x+3x2)(4+5x)=4+13x+22x2+15x3。这个计算过程很直观，但它的工作量随着次数增加得很快。

快速傅里叶变换换了一条路线：先把多项式从“系数表示”转换成“点值表示”，在点值表示下乘法只需要一项一项相乘，最后再转换回系数表示。只要转换和转换回来的过程足够快，整体就会比直接做 n×m 次乘法快得多。

这一节要记住的结论：朴素卷积是 O(nm)；FFT 的目标是把多项式乘法做到 O(L log L)，其中 L 是补零后的大于等于 n+m-1 的 2 的幂。

2. 从系数到点值

一个次数不超过 d 的多项式，由 d+1 个系数唯一确定，也可以由 d+1 个互不相同的点上的取值唯一确定。也就是说，知道 A(x0), A(x1), ..., A(xd)，也能还原出原来的多项式。

把多项式从系数表示变成点值表示，叫做求值；从点值表示变回系数表示，叫做插值。直接求 n 个点的值，每个点都要算 n 项，复杂度是 O(n2)；直接插值同样不便宜。所以“点值表示”本身并不神奇，真正关键的是选什么样的点。

假设我们已经选好了 L 个点 x0, ..., xL-1，并且两个多项式 A、B 在这些点上的值都已知。那么乘积 C=A·B 在同一点上的值就是

C(xi) = A(xi) × B(xi)

只需要 L 次乘法，这就是点值表示最吸引人的地方。问题变成两件事：怎样快速地把系数变成点值，以及怎样快速地把点值变回系数。FFT 选择的点不是随便的整数，而是复平面单位圆上均匀分布的 L 个点，也就是下一节的单位根。

表示方法存储内容乘法代价难点
系数表示a0, a1, ..., an-1O(nm) 次系数对相乘直接卷积太慢
点值表示A(x0), ..., A(xL-1)O(L) 次逐点相乘求值和插值不能太慢

还有一点很重要：两个次数分别为 n-1 和 m-1 的多项式相乘，结果次数最高是 n+m-2，需要 n+m-1 个点才能唯一确定。如果只取 n 个点，乘积的高次项就会丢失，所以后面必须把两个多项式补零到足够长。

3. 单位根与复平面

FFT 使用的特殊点叫做单位根。先回忆复数：i2=-1，一个复数可以写成 a+bi，它在复平面上对应点 (a,b)。欧拉公式告诉我们

eiθ = cos θ + i sin θ

当 θ 从 0 变到 2π 时，eiθ 正好绕单位圆走一圈。把一圈平均分成 n 份，就得到 n 次单位根：

ωn = e2πi/n = cos(2π/n) + i sin(2π/n)

它的 0,1,...,n-1 次幂是 ωn0, ωn1, ..., ωnn-1，对应复平面上均匀分布的 n 个点，并且都满足 zn=1。例如 n=8 时，ω80=1、ω82=i、ω84=-1、ω86=-i。

单位根有两个在 FFT 推导里反复使用的性质。第一，ωnk+n/2 = -ωnk，也就是说相隔半圈的两个点互为相反数；第二，对任意整数 j，

1 + ωnj + ωn2j + ... + ωn(n-1)j = 0（当 n 不整除 j）；= n（当 n 整除 j）

后面会看到，第二条性质是逆变换能够成立的根本原因。现在先动手观察一下这些点。

k = 0

单位根不是“随便选的好算的点”，而是同时满足“均匀分布”“平方后规模减半”“相加有整套消去规律”的点。FFT 的速度正是从这三件事里来的。

4. DFT 与逆 DFT

离散傅里叶变换（Discrete Fourier Transform，DFT）做的事情，就是把系数 a0, ..., an-1 变成多项式在 n 个 n 次单位根上的取值。设

Ak = Σj=0n-1 aj ωnjk，k = 0,1,...,n-1

换句话说，Ak 就是 A(ωnk)。如果直接按定义计算每一个 Ak，每个都要加 n 项，总共 O(n2)，和朴素卷积一样慢。FFT 要解决的就是“怎样在 O(n log n) 内算出所有 Ak”。

DFT 的逆变换长这样：

aj = (1/n) Σk=0n-1 Ak ωn-jk

它和正变换只差两处：指数从 jk 变成 -jk，最后再除以 n。这两处差异在代码里非常关键：逆变换把单位根的旋转方向反过来，并且在所有蝶形运算结束后统一乘上 1/n。如果忘记除以 n，结果会整体放大 n 倍；如果忘记把符号反过来，得到的是另一组值，不是原来的系数。

为什么逆变换公式成立？把右边的 Ak 展开，会得到

(1/n) Σk (Σt at ωntk) ωn-jk = (1/n) Σt at Σk ωn(t-j)k

里面的 Σk ωn(t-j)k 只有在 t=j 时等于 n，其他时候都等于 0；于是整个式子只剩下 aj。这就是上一节那条“整圈相加为零”的性质在起作用。

4.1 用矩阵的眼光看

如果把 a 和 A 都看成列向量，DFT 就是一个矩阵乘法：第 k 行第 j 列的元素是 ωnjk。这个矩阵是对称的，逆矩阵的元素则是 (1/n)ωn-jk。

矩阵乘法直接做是 O(n2)，但单位根矩阵有很强的规律：它的列可以按偶数和奇数拆开，拆开后的两半又分别是一个规模减半的同类矩阵。这种“自己包含自己”的结构，正是分治能够奏效的原因。

正变换：把系数变成单位根上的取值；逆变换：把取值变回系数。两者都用同一套蝶形结构，只是旋转方向相反、最后除以 n。

5. 分治：Cooley–Tukey

下面推导 FFT 最核心的一步。把多项式按次数的奇偶拆成两部分：

A(x) = (a0 + a2x2 + a4x4 + ...) + x(a1 + a3x2 + a5x4 + ...)

令

Ae(y) = a0 + a2y + a4y2 + ...，Ao(y) = a1 + a3y + a5y2 + ...

那么 A(x)=Ae(x2)+x·Ao(x2)。现在把 x 取成 n 次单位根 ωnk，则 x2=ωn2k=ωn/2k。也就是说，Ae 和 Ao 只需要在 n/2 次单位根上求值，规模立刻减半。

设 Ek=Ae(ωn/2k)，Ok=Ao(ωn/2k)。对 k=0,1,...,n/2-1，有

Ak = Ek + ωnk Ok
Ak+n/2 = Ek - ωnk Ok

第二行来自 ωnk+n/2=-ωnk。这两个式子合在一起，就是著名的蝶形运算：一对输入 Ek、Ok，先乘上旋转因子 ωnk，再通过一次加法和一次减法得到一对输出。

于是求一个长度为 n 的 DFT，可以拆成两个长度为 n/2 的 DFT，再加上 n/2 次蝶形合并。写成分治式：

T(n) = 2T(n/2) + O(n) = O(n log n)

递归树每一层要处理总共 n 个数据，一共有 log2n 层。只要 n 是 2 的幂，就能一直对半拆到长度为 1；长度 1 的 DFT 就是它自己，不需要计算。

分治公式要求 n 是 2 的幂。实际输入长度不是 2 的幂时，先补零到不小于 n+m-1 的 2 的幂；否则“对半拆”会在某一层拆不下去。

6. 位逆序与迭代实现

递归写法最直观：把偶数项交给左半边，奇数项交给右半边，递归到底，再一层层合并。但真正的竞赛代码更常用迭代写法，因为递归有函数调用开销，而且每层都要复制数组。迭代写法的关键，是先把输入按位逆序排好。

以 n=8 为例，下标 0..7 写成 3 位二进制，把二进制位左右翻转，就得到它在新数组中的位置。比如 3=(011)2 翻转后是 (110)2=6，所以原数组的第 3 项应该放到第 6 个位置。翻转后的顺序是：

原下标二进制翻转后新下标
00000000

20100102
30111106
41000011
51011015
61100113
71111117

排好之后，从长度为 2 的小块开始，逐步合并成长度为 4、8、... 的大块。每一轮里，相邻两块相同位置的数据正好组成一个蝶形：一个留在原位，一个乘上旋转因子，然后做加减。这样就不需要递归，只需要一层循环控制块长，一层循环控制块内位置。

位逆序可以在 O(n) 时间内完成：从 i=1 开始维护一个翻转后的下标 j，每次把 j 的最高位“进位”到低位；当 i<j 时交换 a[i] 和 a[j]，避免同一对换两次。下面这个交互表可以切换长度，看看每一对下标是怎样配对的。

n = 8：交换 (1,4)、(3,6)；0、2、5、7 位置不变。

注意位逆序只改变元素的排列顺序，不改变元素的值。完成这一步后，迭代 FFT 的每一层都只处理连续的一段，代码里通常写成 for (int len=2; len<=n; len<<=1)，再用 for (int i=0; i<n; i+=len) 枚举每一块。下一节的完整代码就是按这个结构写的。

7. 完整代码：迭代版

下面的程序把前面的步骤完整地串了起来：读入两个多项式，补零到 2 的幂，做正向 FFT，逐点相乘，做逆向 FFT，最后四舍五入并输出系数。输入格式是：第一行第一个多项式的项数 n，第二行 n 个系数；第三行第二个多项式的项数 m，第四行 m 个系数。系数按 a0,a1,...,an-1 的顺序给出。

样例输入的两个多项式是 A(x)=1+2x+3x2 和 B(x)=4+5x。结果有 3+2-1=4 项，补零后的长度 L=4。程序输出 4 13 22 15，正好对应 4+13x+22x2+15x3。

#include <iostream>                     // 标准输入输出
#include <vector>                       // 动态数组
#include <complex>                      // 复数类型
#include <cmath>                        // cos、sin、acos、llround
using namespace std;                     // 使用标准命名空间

const double PI = acos(-1.0);           // 圆周率，用于计算单位根角度

void fft(vector<complex<double>> &a, bool invert) { // 迭代版 FFT，invert 表示逆变换
    int n = (int)a.size();             // 当前多项式长度，必须是 2 的幂
    for (int i = 1, j = 0; i < n; ++i) { // 位逆序置换：把下标换成二进制反转后的位置
        int bit = n >> 1;              // 从最高位开始试探
        while (j & bit) {              // 当前位已经是 1
            j ^= bit;                  // 把它清成 0，继续看下一位
            bit >>= 1;                 // 右移一位
        }                              // 进位处理结束
        j ^= bit;                      // 把第一个 0 位变成 1
        if (i < j) {                   // 只在 i 小于 j 时交换，避免换回去
            swap(a[i], a[j]);          // 交换两个系数
        }                              // 交换判断结束
    }                                  // 位逆序结束
    for (int len = 2; len <= n; len <<= 1) { // len 是当前合并的两个半区总长度
        double angle = 2 * PI / len * (invert ? -1 : 1); // 逆变换时角度取负
        complex<double> wlen(cos(angle), sin(angle)); // 当前层的主单位根
        for (int i = 0; i < n; i += len) { // 每 len 个元素做一组蝶形
            complex<double> w(1, 0);   // 单位根的 0 次方
            for (int j = 0; j < len / 2; ++j) { // 只枚举前半部分
                complex<double> u = a[i + j]; // 左半边的值
                complex<double> v = a[i + j + len / 2] * w; // 右半边乘单位根
                a[i + j] = u + v;      // 蝶形运算的加号支路
                a[i + j + len / 2] = u - v; // 蝶形运算的减号支路
                w *= wlen;             // 旋转到下一个单位根
            }                          // 一组蝶形结束
        }                              // 当前层结束
    }                                  // 所有层结束
    if (invert) {                      // 逆变换的结果需要归一化
        for (int i = 0; i < n; ++i) {  // 遍历每个系数
            a[i] /= n;                 // 除以长度 n
        }                              // 归一化结束
    }                                  // 逆变换判断结束
}                                      // fft 函数结束

vector<int> multiply(const vector<int> &a, const vector<int> &b) { // 用 FFT 求多项式乘积
    if (a.empty() || b.empty()) {      // 只要有一个多项式为空
        return {};                     // 乘积就是空多项式
    }                                  // 空判断结束
    int need = (int)a.size() + (int)b.size() - 1; // 乘积最多有这么多项
    int n = 1;                         // 找不小于 need 的最小的 2 的幂
    while (n < need) {                 // 长度还不够
        n <<= 1;                       // 长度翻倍
    }                                  // 找长度结束
    vector<complex<double>> fa(a.begin(), a.end()); // 把 a 复制成复数数组
    vector<complex<double>> fb(b.begin(), b.end()); // 把 b 复制成复数数组
    fa.resize(n);                      // 末尾补 0 到长度 n
    fb.resize(n);                      // 末尾补 0 到长度 n
    fft(fa, false);                    // 对 a 做正向 FFT
    fft(fb, false);                    // 对 b 做正向 FFT
    for (int i = 0; i < n; ++i) {      // 枚举每个频率
        fa[i] *= fb[i];                // 点值表示下直接相乘
    }                                  // 点乘结束
    fft(fa, true);                     // 逆 FFT 变回系数
    vector<int> res(need);             // 只保留真正需要的项
    for (int i = 0; i < need; ++i) {   // 逐项取实部
        res[i] = (int)llround(fa[i].real()); // 四舍五入成整数
    }                                  // 取整结束
    return res;                        // 返回乘积系数
}                                      // multiply 函数结束

int main() {                           // 主函数
    ios::sync_with_stdio(false);       // 关闭 C 与 C++ 的输入同步
    cin.tie(nullptr);                  // 解除 cin 与 cout 的绑定
    int n;                             // 第一个多项式的项数
    if (!(cin >> n)) {                 // 读入失败
        return 0;                      // 直接结束
    }                                  // 读入判断结束
    vector<int> a(n);                  // 第一个多项式的系数
    for (int i = 0; i < n; ++i) {      // 逐项读入
        cin >> a[i];                   // 第 i 项系数
    }                                  // 读入 a 结束
    int m;                             // 第二个多项式的项数
    cin >> m;                          // 读入 m
    vector<int> b(m);                  // 第二个多项式的系数
    for (int i = 0; i < m; ++i) {      // 逐项读入
        cin >> b[i];                   // 第 i 项系数
    }                                  // 读入 b 结束
    vector<int> c = multiply(a, b);    // 计算乘积
    for (int i = 0; i < (int)c.size(); ++i) { // 输出乘积的每一项
        if (i > 0) {                   // 不是第一项
            cout << ' ';               // 输出分隔空格
        }                              // 空格判断结束
        cout << c[i];                  // 输出系数
    }                                  // 输出结束
    cout << '\n';                      // 输出换行
    return 0;                          // 程序正常结束
}                                      // main 函数结束

7.1 样例

输入：

3
1 2 3
2
4 5

输出：

7.2 代码执行路线

  1. main 读入两个数组，调用 multiply。
  2. multiply 先算出结果需要的项数 need=n+m-1，再把长度扩展到不小于 need 的 2 的幂 L。
  3. 把两个系数数组复制成 complex<double> 数组，末尾补 0。
  4. fft(fa,false) 和 fft(fb,false) 把两个多项式变成点值。
  5. 逐点相乘：fa[i] *= fb[i]。
  6. fft(fa,true) 做逆变换，并在函数内部除以 L。
  7. 取实部，用 llround 四舍五入，截取前 need 项输出。
位逆序置换在 fft 的开头完成，而且只做一次；后面的每一层 len 都在已经排好序的数组上做蝶形，不需要再次翻转。逆变换和正变换共用同一个函数，只通过 invert 改变角度符号和最后的归一化。
这份代码用 vector<int> 保存结果，适合结果系数在 int 范围内的题目。如果系数可能很大，应该把结果类型改成 long long，并同时考虑浮点精度是否足够；具体见第 10 节。

8. 卷积：补零、点乘、逆变换

现在把多项式乘法完整地写成卷积流程。设 A 的长度为 n，B 的长度为 m，乘积的长度为 n+m-1。FFT 要求长度是 2 的幂，所以先取

L = 2⌈log2(n+m-1)⌉

把两个系数数组都补零到长度 L。补零不会改变多项式，因为补上去的系数都是 0，只是让数组长度变成 FFT 能处理的 2 的幂。然后执行三步：

  1. 正变换：对 A 和 B 分别做 FFT，得到两组点值 FA、FB。
  2. 点乘：对每个 i，令 FC[i]=FA[i]×FB[i]。这一步是 O(L)。
  3. 逆变换：对 FC 做逆 FFT，再除以 L，得到乘积的系数。

用样例走一遍：A 补零成 [1,2,3,0]，B 补零成 [4,5,0,0]，长度 L=4。两组点值逐项相乘后做逆变换，前四项取整就是 [4,13,22,15]。也可以补到 8 项，只要长度是 2 的幂并且不小于 4；但多补的零只会增加计算量，所以通常取最小的那个 2 的幂。

阶段操作复杂度
补零把长度补到 L（2 的幂）O(L)
正变换两次 FFTO(L log L)
点乘FA[i] *= FB[i]O(L)
逆变换一次逆 FFT，再除以 LO(L log L)
取整llround 取实部O(n+m)

浮点运算会带来很小的误差，所以不能直接把 real() 截断成整数，而要用 llround 四舍五入。对于系数不太大的整数卷积，误差通常远小于 0.5，四舍五入可以恢复出正确整数；如果系数很大，误差可能超过 0.5，这时要考虑 long double 或改用 NTT。

下面这个小工具会同时用朴素卷积和 FFT 计算你输入的两个多项式，并把两种结果放在一起比较。输入时用空格分隔系数，例如 1 2 3 表示 1+2x+3x2。

只接受整数系数；结果会同时显示朴素卷积和 FFT 的结果。

点击“计算卷积”查看结果。

9. 完整代码：递归版

递归版直接照着分治公式写：把当前数组按奇数位、偶数位拆成两半，分别递归，再用蝶形合并。它没有位逆序，也不需要迭代的块长控制，读起来更接近数学推导，但每层都要开辟两个新数组，函数调用和内存分配的开销更大。

#include <iostream>                     // 标准输入输出
#include <vector>                       // 动态数组
#include <complex>                      // 复数类型
#include <cmath>                        // cos、sin、acos、llround
using namespace std;                     // 使用标准命名空间

const double PI = acos(-1.0);           // 圆周率

void fft_rec(vector<complex<double>> &a, bool invert) { // 递归 FFT 的核心过程
    int n = (int)a.size();             // 当前长度
    if (n == 1) {                      // 只剩一个系数
        return;                        // 递归出口
    }                                  // 出口判断结束
    vector<complex<double>> a0(n / 2), a1(n / 2); // 偶次项和奇次项
    for (int i = 0; i < n / 2; ++i) {  // 按下标的奇偶分组
        a0[i] = a[2 * i];              // 第 2i 项放到偶数组
        a1[i] = a[2 * i + 1];          // 第 2i+1 项放到奇数组
    }                                  // 分组结束
    fft_rec(a0, invert);               // 递归求偶数组
    fft_rec(a1, invert);               // 递归求奇数组
    double angle = 2 * PI / n * (invert ? -1 : 1); // 本层的单位根角度
    complex<double> w(1, 0);           // 从 1 次方开始
    complex<double> wlen(cos(angle), sin(angle)); // 本层主单位根
    for (int i = 0; i < n / 2; ++i) {  // 合并两个半区
        complex<double> t = w * a1[i]; // 奇数组乘上单位根
        a[i] = a0[i] + t;              // 前半部分
        a[i + n / 2] = a0[i] - t;      // 后半部分
        w *= wlen;                     // 旋转到下一个单位根
    }                                  // 合并结束
}                                      // fft_rec 函数结束

void fft(vector<complex<double>> &a, bool invert) { // 递归版 FFT 的入口
    int n = (int)a.size();             // 保存原长度
    fft_rec(a, invert);                // 先做递归蝶形
    if (invert) {                      // 逆变换需要归一化
        for (int i = 0; i < n; ++i) {  // 遍历所有系数
            a[i] /= n;                 // 除以长度 n
        }                              // 归一化结束
    }                                  // 逆变换判断结束
}                                      // fft 函数结束

vector<int> multiply(const vector<int> &a, const vector<int> &b) { // 多项式乘法
    if (a.empty() || b.empty()) {      // 有空多项式
        return {};                     // 返回空
    }                                  // 空判断结束
    int need = (int)a.size() + (int)b.size() - 1; // 结果项数
    int n = 1;                         // 补零后的长度
    while (n < need) {                 // 找不小于 need 的 2 的幂
        n <<= 1;                       // 翻倍
    }                                  // 找长度结束
    vector<complex<double>> fa(a.begin(), a.end()); // 复制第一个多项式
    vector<complex<double>> fb(b.begin(), b.end()); // 复制第二个多项式
    fa.resize(n);                      // 补零
    fb.resize(n);                      // 补零
    fft(fa, false);                    // 正向 FFT
    fft(fb, false);                    // 正向 FFT
    for (int i = 0; i < n; ++i) {      // 逐点相乘
        fa[i] *= fb[i];                // 点值相乘
    }                                  // 点乘结束
    fft(fa, true);                     // 逆 FFT
    vector<int> res(need);             // 结果数组
    for (int i = 0; i < need; ++i) {   // 取实部并四舍五入
        res[i] = (int)llround(fa[i].real()); // 转成整数
    }                                  // 取整结束
    return res;                        // 返回结果
}                                      // multiply 函数结束

int main() {                           // 主函数
    ios::sync_with_stdio(false);       // 关闭输入同步
    cin.tie(nullptr);                  // 解除绑定
    int n;                             // 第一个多项式项数
    if (!(cin >> n)) {                 // 读入失败
        return 0;                      // 结束
    }                                  // 判断结束
    vector<int> a(n);                  // 第一个多项式
    for (int i = 0; i < n; ++i) {      // 逐项读入
        cin >> a[i];                   // 第 i 项
    }                                  // 读入结束
    int m;                             // 第二个多项式项数
    cin >> m;                          // 读入 m
    vector<int> b(m);                  // 第二个多项式
    for (int i = 0; i < m; ++i) {      // 逐项读入
        cin >> b[i];                   // 第 i 项
    }                                  // 读入结束
    vector<int> c = multiply(a, b);    // 计算乘积
    for (int i = 0; i < (int)c.size(); ++i) { // 输出每一项
        if (i > 0) {                   // 不是第一项
            cout << ' ';               // 输出空格
        }                              // 判断结束
        cout << c[i];                  // 输出系数
    }                                  // 输出结束
    cout << '\n';                      // 换行
    return 0;                          // 正常结束
}                                      // main 函数结束

9.2 两种写法怎么选

比较项迭代版递归版
核心结构位逆序 + 自底向上的块合并奇偶分组 + 自顶向下递归

递归深度无O(log L)
常数与速度通常更快，适合竞赛更容易对照公式，适合理解

两份代码的 multiply 完全相同：补零、正变换、点乘、逆变换、取整。真正不同的只有 fft 的内部实现。因此只要把其中一份的 fft 换掉，另一部分可以原样复用。

10. 精度、范围与常见坑

FFT 用 double 做复数运算，而计算机里的浮点数不是精确的。C++ 的 double 通常有 53 位二进制有效数字，约等于十进制的 15 到 16 位有效数字。单位根、旋转因子、每次乘加都会带来一点舍入误差，这些误差会在 log L 层里累积。

对于整数卷积，一个常用的粗略判断是看结果系数的最大可能值。如果两个多项式的系数绝对值都不超过 M，那么卷积系数的绝对值大致不超过 M2×min(n,m)。当这个上界接近 1015 时，double 的精度已经很紧张；如果接近或超过 1016，四舍五入就可能出错，应该改用 long double、把系数拆成高低位，或者使用 NTT。

现象常见原因处理办法
结果整体是正确答案的 L 倍逆变换后忘记除以 L检查 fft(...,true) 的归一化
结果顺序对不上，像被“打乱”位逆序写错，或逆变换方向错先单独测试 n=4、n=8
高位结果变成 0 或很小补零长度小于 n+m-1取不小于 n+m-1 的 2 的幂
末尾几位差 1浮点误差接近 0.5用 llround；增大精度或改 NTT
大系数结果明显错误int 溢出或 double 精度不够结果改 long long；必要时用 NTT
多组数据第二组开始出错数组、计数器没有重新初始化每组数据重新构造 FFT 数组
本页代码返回 vector<int>，是假设结果能放进 int。如果题目要求对 998244353 取模，或者系数乘积可能超过 2×109，就不能直接照搬：取模题通常使用 NTT；不取模但结果很大时，至少要把结果换成 long long，并重新评估精度。

还有一个容易忽视的问题：输入的系数是整数，但 FFT 内部把它们看成实数；如果系数本身很大，complex<double> 在存储时就已经损失精度，后面再好的算法也救不回来。所以精度问题要在建模阶段就判断，而不是等结果错了才检查代码。

11. 复杂度、对比与扩展

设两个多项式长度分别为 n 和 m，补零后的长度为 L，则 L 是大于等于 n+m-1 的最小 2 的幂。FFT 要做两次正变换和一次逆变换，每次 O(L log L)，所以总复杂度是 O(L log L)，空间是 O(L)。

方法时间复杂度空间复杂度适用情况
朴素卷积O(nm)O(n+m)长度很小，或系数需要精确整数运算
迭代 FFTO(L log L)O(L)长度较大、结果可用浮点恢复的整数卷积
递归 FFTO(L log L)O(L log L)（临时数组总量）理解分治、教学和小数据
NTTO(L log L)O(L)模数为特定质数、要求完全精确

当 n=m=105 时，朴素卷积要乘 1010 次，而 L 约为 218，L log2L 大约是 4.7×106；即使 FFT 的常数比一次乘法大很多，差距仍然非常明显。长度越大，FFT 的优势越明显。

FFT 也不是终点。竞赛里常见的扩展有：

  • NTT：把复数单位根换成模质数下的单位根，全程整数运算，没有浮点误差，常用于模 998244353 的卷积。
  • MTT：用多次 NTT 或拆系数的方法处理任意模数卷积。
  • 分治 FFT：处理形如 f[i]=Σ f[j]g[i-j] 的递推，边分治边卷积。
  • 字符串匹配：把字符映射成数值，用卷积统计匹配位置，可以处理带通配符的匹配。
  • 大整数乘法：把十进制数看成多项式系数，卷积后再统一进位。

想继续深入，可以阅读 OI Wiki 的 FFT 页面 和 cp-algorithms 的 FFT 教程；想练习模板题，可以做 洛谷 P3803 多项式乘法。如果题目要求取模，先看 NTT，不要直接用本页的浮点代码交题。

12. 总结与练习

FFT 的核心思想可以用一句话概括：用单位根把系数表示转换成点值表示，在点值表示下逐点相乘，再用逆变换转换回来。为了把转换做到 O(n log n)，它利用了单位根的对称性和多项式的奇偶分拆，把一个大 DFT 拆成两个规模减半的 DFT，再用蝶形运算合并。

12.1 一页检查清单

  • 补零后的长度 L 是 2 的幂，并且 L ≥ n+m-1。
  • 正向 FFT 的角度是 +2π/len，逆向是 -2π/len。
  • 逆变换最后要除以 L，而且只除一次。
  • 位逆序在迭代版中只做一次，位置在每一层蝶形之前。
  • 蝶形里先算 v = 右半 × w，再算 u+v 和 u-v。
  • 旋转因子每做完一个蝶形就乘一次 wlen，不要在同一层里重复从 1 开始。
  • 取整用 llround，不要直接截断；负数也要正确四舍五入。
  • 结果类型要能装下最大系数；浮点精度不够时换 NTT。

12.2 练习

  2. 把本页迭代版代码改成输出每个阶段的数组，验证 n=8 时位逆序的结果。

  4. 用 FFT 计算两个大整数的乘积：把十进制数的每一位看成系数，卷积后从低位到高位处理进位。
