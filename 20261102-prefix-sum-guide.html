01前缀和：一次预处理，换来 O(1) 查区间

一句话结论：把「从第 1 个数加到第 i 个数」的结果提前算好存进数组，以后问「第 l 个数到第 r 个数的和」，只要做一次减法。

先看一个生活里的场景

你有一个存钱罐。每天往里放一点钱，同时在旁边的小本子上记一行字：「到今天为止，罐子里一共有多少钱」。

过了一个星期，妈妈问你：星期三到星期五，这三天你一共放进去多少钱？

你不需要把这三天的钱重新倒出来数一遍。小本子上已经写着「到星期五一共多少」和「到星期二一共多少」，两个数一减，就是这三天放进去的总数。这个「小本子上的累计数」，就是前缀和。

定义与递推

给定一个从 1 开始编号的数列 a1, a2, …, an，我们定义前缀和数组 s：

si = a1 + a2 + ⋯ + ai     特别规定 s0 = 0

直接照着定义算，si 要把前面 i 个数加一遍，n 个前缀和加起来是 O(n²)。但注意到一件很朴素的事：算到第 i 个的时候，前面 i−1 个的和已经算过了，直接拿来用就行。于是有递推式：

si = si−1 + ai     i 从 1 到 n

这样预处理一遍只要 O(n)。

查询：一次减法

要问区间 [l, r] 的和，就用「前 r 个的和」减去「前 l−1 个的和」：

sum(l, r) = sr − sl−1

为什么对？因为 sr 里包含了 a1…ar 全部，sl−1 里包含了 a1…al−1，两者一减，前面那一段刚好抵消掉，剩下的正好是 al…ar。

拿具体数字走一遍

设 a = {3, 1, 4, 1, 5}

前缀和：s = {0, 3, 4, 8, 9, 14}

其中 s0=0，s1=0+3=3，s2=3+1=4，s3=4+4=8，s4=8+1=9，s5=9+5=14。

问 [2, 4] 的和：s4 − s1 = 9 − 3 = 6。验证一下：1 + 4 + 1 = 6，对上了。

基础模板（逐行注释）

下面这段是 PDF 第 1 页给出的基础模板，把「建立前缀和、查询区间、建立差分、区间修改、用差分还原」五个操作放在了一起：

基础模板 · 前缀和与差分
#include <iostream>                                     // 引入输入输出流

const int N = 1e5 + 10;                                 // 数组最大长度，多开 10 个防越界
long long a[N];                                         // 原数组 a
long long sum[N];                                       // 前缀和数组
long long diff[N];                                      // 差分数组

void build_prefix_sum(int n) {                          // 建立前缀和
    for (int i = 1; i <= n; ++i) {                      // 从第 1 个元素扫到第 n 个
        sum[i] = sum[i - 1] + a[i];                     // 当前前缀和 = 前一项前缀和 + 当前元素
    }
}

long long query_sum(int l, int r) {                     // 查询区间 [l, r] 的和
    return sum[r] - sum[l - 1];                         // O(1)：右端前缀和 减 左端前一位前缀和
}

void build_difference(int n) {                          // 建立差分数组
    for (int i = 1; i <= n; ++i) {                      // 从第 1 个元素扫到第 n 个
        diff[i] = a[i] - a[i - 1];                      // 差分 = 当前元素 减 前一个元素
    }
}

void update_range(int l, int r, long long v) {          // 把区间 [l, r] 统一加上 v
    diff[l] += v;                                       // 左端点 +v：从 l 开始生效
    diff[r + 1] -= v;                                   // 右端后一位 -v：到 r+1 撤销
}

void recover_from_difference(int n) {                   // 用差分数组还原原数组
    for (int i = 1; i <= n; ++i) {                      // 从第 1 个元素扫到第 n 个
        a[i] = a[i - 1] + diff[i];                      // 对差分求前缀和，就变回 a
    }
}
两个必须注意的细节。第一，数组从下标 1 开始用，并且 s[0] 要留出来等于 0，否则 l = 1 的时候访问 s[l−1] 就会越界。第二，a 是 int 的时候也要小心：累加过程中的和可能早就超过 int 的范围了，所以前缀和数组要用 long long。
前缀和 = 提前把「一路加到这儿」的结果存起来，查询时两端相减。

02差分：一次预处理，换来 O(1) 改区间

一句话结论：差分数组记的是「后一个数减前一个数」。想让一整段区间同时加上 v，不用挨个改，只要改两个位置。

还是从一个场景说起

班主任要给第 3 号到第 10 号同学每人加 5 分。最直接的办法是翻名单，一个一个改，一共改 8 个人。

但也可以换个记法：在名单边上写两句话 ——「从第 3 号开始，每人 +5」「从第 11 号开始，每人 −5」。最后从头念一遍，一边念一边把这两句话的效力累加起来，念到谁，谁该加多少就自动出来了。念到第 3 号时是 +5，一直保持到第 10 号；念到第 11 号时加上 −5，正好抵消回 0。

这个「只记变化点」的数组，就是差分数组。它把「改一段」变成了「改两个点」。

定义与还原

差分数组 d 定义为相邻两项的差：

di = ai − ai−1     规定 a0 = 0

反过来，已知差分数组，把前缀和一层层加回去，就能恢复原数组：

ai = ai−1 + di

这一步就是「对差分数组求前缀和」，复杂度 O(n)。

区间修改：两次单点操作

把区间 [l, r] 里每个数都加上 v，在差分数组上只需要两下：

dl ← dl + v      dr+1 ← dr+1 − v

道理和班主任那两句话完全一样：在 l 处「开始加」，加的效果会随着前缀和一路传下去；到 r+1 处「停止加」，减回来，正好把影响截断在 r。中间这一段就整体抬高了 v。

拿具体数字走一遍

设 a = {3, 1, 4, 1, 5}，则差分 d = {3, −2, 3, −3, 4}。

把区间 [2, 4] 每个数都加 10：d2 += 10 变成 8；d5 −= 10 变成 −6。

新的 d = {3, 8, 3, −3, −6}。

还原：a1=3，a2=3+8=11，a3=11+3=14，a4=14−3=11，a5=11−6=5。

得到 {3, 11, 14, 11, 5}，正好是原数组的第 2、3、4 位各加了 10。

两个必须注意的细节。第一，差分数组要开到 n + 2：修改右端点是 n 的时候会访问 d[n+1]，空间不够就是段错误。第二，所有修改都做完之后，再统一求前缀和还原；不要一边改一边还原，否则后面的修改会作用在已经变了的值上。
区间修改 = 在 l 处加一枪，在 r+1 处拆一枪，最后从头累加一遍。

03为什么说它们是「互逆」的一对

PDF 第 1 页有一句话：它们是一对互逆操作。这句话值得单独说清楚，因为它决定了你做题时该选哪个。

把数组 a 看成一条路，前缀和是「往后一直累加」，差分是「相邻两项相减」。这两件事刚好互相抵消：对 a 求差分得到 d，再对 d 求前缀和，又回到 a；反过来先求前缀和再求差分，同样回到 a。

对比项 前缀和 差分
怎么算 s[i] = s[i-1] + a[i]（累加） d[i] = a[i] - a[i-1]（作差）
擅长什么 区间查询，一次减法 O(1) 区间修改，两次单点 O(1)
不擅长什么 区间修改（要重新算一遍 O(n)） 区间查询（要先还原 O(n)）
预处理代价 O(n) 读入时顺手就建好了，O(n)
整体复杂度 O(n + m)（m 次查询） O(n + p)（p 次修改）
怎么选：题目里「问很多次，几乎不改」——用前缀和；「改很多次，最后只问一次」——用差分。两个都要又改又问，那就得上树状数组或者线段树了。
差分求前缀和回到原数组，原数组求差分得到差分数组，这两步互相抵消。

04离散化：值域很大时把数字压缩成排名

一句话结论：当数字很大、但个数并不多的时候，把每个数换成它「排第几名」，大小顺序一点不变，数字却变得很小，数组就开得下了。

为什么需要它

PDF 里写得很直接：在线段树、树状数组这类结构里，空间消耗与值域跨度正相关。也就是说，数组要开多大，看的是「最大值减最小值」这个跨度，而不是「一共有多少个数」。

举个具体的：N = 10⁵ 个数，每个数的值可能到 10⁹ 级别。你不可能开一个 10⁹ 大小的数组，内存直接爆掉。但这 10⁵ 个数之间，真正有意义的只有它们的大小顺序，至于 100 和 1000000 之间差了多少，很多时候根本用不上。

离散化做的事就是：丢掉「间隔有多大」，只保留「谁比谁大」。10⁵ 个数最多只有 10⁵ 种不同的取值，压缩完下标就落在 1 到 N 之间，稳稳开得下。

班级排身高

一个班 50 个人，身高如果用毫米记，是 1732、1655、1890 这种数字。但其实我们只关心「谁第几高」。把它们换成 1、2、3……50 的排名，比较大小的结果完全一样，数字却小了两个数量级。这就是离散化的全部想法。

三步走

  1. 收集：把所有需要用到的大数值，统统装进一个辅助数组 vals。
  2. 排序去重：sort 从小到大排好，unique 把重复的挪到末尾并返回新的尾位置，erase 把它们真正删掉。做完之后 vals 里是严格递增的一串数。
  3. 查排名：对每个数 x，用 lower_bound 找到第一个大于等于 x 的位置，这个位置的下标加 1，就是 x 的排名（从 1 开始数）。

PDF 里特别点出：利用 std::vector 结合 <algorithm> 库的 sort、unique 和 lower_bound，是常用实现方式。

拿具体数字走一遍

设 a = {1000000000, 5, 999, 5, 42}。

收集去重排序后：vals = {5, 42, 999, 1000000000}。

查排名：5 → 1，42 → 2，999 → 3，10⁹ → 4。

离散化后的数组：{4, 1, 3, 1, 2}。原来最大的还是最大，最小的还是最小，只是数字从十亿变成了个位数。

离散化模板（逐行注释）

离散化 · 通用模板
#include <iostream>                                     // 输入输出
#include <vector>                                       // 动态数组 vector
#include <algorithm>                                    // sort / unique / lower_bound 都在这里

const int N = 1e5 + 10;                                 // 数组最大长度
int a[N];                                               // 原数组
std::vector<int> vals;                                  // 存放所有数值，用来离散化

int get_rank(int x) {                                   // 求数值 x 的排名（从 1 开始）
    // lower_bound 返回第一个大于等于 x 的元素的迭代器
    // 减去起始迭代器得到从 0 开始的下标，加 1 转换为 1-based 排名
    return std::lower_bound(vals.begin(), vals.end(), x) - vals.begin() + 1;
}

void discretize(int n) {                                // 离散化主函数
    for (int i = 1; i <= n; ++i) {                      // 第 1 步：收集所有数值
        vals.push_back(a[i]);                           // 把 a[i] 装进 vals
    }
    std::sort(vals.begin(), vals.end());                // 第 2 步：从小到大排序
    // unique 把重复元素挪到末尾，返回去重后有效区间的尾迭代器
    vals.erase(std::unique(vals.begin(), vals.end()), vals.end());   // 第 3 步：真正删掉重复的
    for (int i = 1; i <= n; ++i) {                      // 第 4 步：把原数组换成排名
        a[i] = get_rank(a[i]);                          // a[i] 变成它的排名
    }
}
别忘了原始数值。离散化之后 a 里存的只是排名，原来的具体数值就没了。如果后面要算「这一段实际有多长」，就得留着 vals，用 vals[rank − 1] 查回去。例题三马上就会用到这一点。
离散化 = 把「数值」换成「名次」，排名之间的差不再是真实距离。

05例题一 P8218 求区间和（前缀和）

题目在说什么

给一个长度为 n 的正整数数列，再给 m 次询问，每次问区间 [l, r] 里所有元素的和。数据范围是 1 ≤ n, m ≤ 10⁵，1 ≤ ai ≤ 10⁴。

如果每次询问都把区间里的数挨个加一遍，一次最坏要加 n 个数，m 次就是 10¹⁰ 次操作，肯定超时。

用哪个工具

只查不改，天生就是前缀和的主场。

数学模型

si = Σj=1…i aj     s0 = 0
sum(l, r) = sr − sl−1

解题思路

  1. 预处理：读入数列的时候顺手递推 si = si−1 + ai，时间复杂度 O(n)。
  2. 查询：每次询问直接套公式 sr − sl−1，单次 O(1)。
  3. 总复杂度：时间 O(n + m)，空间 O(n)。

核心代码

P8218 · 核心代码
vector<long long> s(n + 1, 0);          // 前缀和数组，长度 n+1，初值全 0
for (int i = 1; i <= n; i++) {          // 从 1 扫到 n
    long long x;                        // 当前读入的数
    cin >> x;                           // 读入 a[i]
    s[i] = s[i - 1] + x;                // 边读边累加，得到前缀和
}
while (m--) {                           // 处理 m 次询问
    int l, r;                           // 询问区间 [l, r]
    cin >> l >> r;                      // 读入左右端点
    cout << s[r] - s[l - 1] << "\n";    // 一次减法得到答案
}

完整代码

    ios::sync_with_stdio(false);                // 关掉 cin/cout 与 C 输入输出的同步

        long long x;                            // 当前读入的数
        cin >> x;                               // 读入 a[i]

    }

        int l, r;                               // 询问区间 [l, r]

本题坑点

坑点一：前缀和数组必须从 0 开始存，并且令 s0 = 0。这样当左端点 l = 1 时，访问 sl−1 拿到的就是 s0，不会出错。
坑点二：虽然本题的数值很小（ai ≤ 10⁴），但累加之后的和完全可能超出 int 范围。前缀和数组建议直接用 long long，别心疼那点内存。

06例题二 P2367 语文成绩（差分）

题目在说什么

班上有 n 名同学，给出他们现在的语文成绩，然后做 p 次操作：每次把第 x 名到第 y 名同学的成绩都加上 z。所有操作做完之后，求全班的最低分。

数据范围 1 ≤ n ≤ 5×10⁶，p ≤ n。n 有五百万这么大，如果每次操作都老老实实地把区间里每个人挨个加一遍，光是操作就有 n×p 次，绝对过不去。

用哪个工具

改很多次、最后只问一次，这就是差分。

数学模型

di = ai − ai−1     规定 a0 = 0

原数组可以通过对差分数组求前缀和恢复。区间 [x, y] 整体加 z，在差分数组上化成两次单点修改：

dx ← dx + z      dy+1 ← dy+1 − z

解题思路

  1. 构造差分数组：读入初始成绩的时候，记住前一个值，当前值减前一个值存进 d 数组。
  2. 处理修改：p 次操作，每次就是 O(1) 的两行差分更新。
  3. 恢复并求极值：对差分数组从头求前缀和，一边还原一边维护最小值。
  4. 总复杂度：时间 O(n + p)，空间 O(n)。

核心代码

P2367 · 核心代码
for (int i = 1; i <= n; i++) {          // 读入初始成绩，同时建差分
    ll x;                               // 当前成绩
    cin >> x;                           // 读入 a[i]
    d[i] = x - prev;                    // 差分 = 当前成绩 - 前一个成绩
    prev = x;                           // 更新 prev，留给下一个用
}
while (p--) {                           // 处理 p 次修改
    int x, y;                           // 修改区间 [x, y]
    ll z;                               // 加上的分数
    cin >> x >> y >> z;                 // 读入三个数
    d[x] += z;                          // 左端点 +z
    d[y + 1] -= z;                      // 右端后一位 -z
}
ll cur = 0, ans = LLONG_MAX;            // cur 是当前成绩，ans 是最低分
for (int i = 1; i <= n; i++) {          // 一遍扫过去还原
    cur += d[i];                        // 前缀和还原出第 i 个学生的成绩
    ans = min(ans, cur);                // 更新最低分
}

完整代码

P2367 · 完整代码
#include <bits/stdc++.h>                        // 万能头文件
using namespace std;                            // 省去 std::
using ll = long long;                           // 给 long long 起个短名字 ll
const int MAXN = 5000005;                       // 学生人数上限 5×10^6

ll d[MAXN];                                     // 差分数组，全局变量默认全 0

int main() {                                    // 主函数
    ios::sync_with_stdio(false);                // 关同步，加速读入
    cin.tie(nullptr);                           // 解绑定，加速读入

    int n, p;                                   // n 个学生，p 次修改
    cin >> n >> p;                              // 读入 n 和 p
    ll prev = 0;                                // 记前一个成绩，把 a[0] 当成 0
    for (int i = 1; i <= n; i++) {              // 读入初始成绩并建差分
        ll x;                                   // 当前成绩
        cin >> x;                               // 读入 a[i]
        d[i] = x - prev;                        // 差分：当前成绩 减 前一个成绩
        prev = x;                               // 更新 prev
    }

    while (p--) {                               // 处理 p 次修改
        int x, y;                               // 修改区间 [x, y]
        ll z;                                   // 加上的分数 z
        cin >> x >> y >> z;                     // 读入三个数
        d[x] += z;                              // 左端点 +z：从这里开始加
        d[y + 1] -= z;                          // 右端后一位 -z：到这里撤销
    }

    ll cur = 0;                                 // 当前成绩（差分前缀和）
    ll ans = LLONG_MAX;                         // 最低分，先设成 long long 最大值
    for (int i = 1; i <= n; i++) {              // 一遍扫过去还原
        cur += d[i];                            // 前缀和还原出第 i 个学生的成绩
        ans = min(ans, cur);                    // 更新最低分
    }
    cout << ans << "\n";                        // 输出最低分
    return 0;                                   // 正常结束
}

本题坑点

坑点一：差分数组的大小必须开到 n + 2。当修改区间的右端点正好是 n 时，会访问 d[n+1]，空间不够就是段错误。
坑点二：必须在所有区间修改指令处理完毕之后，再统一通过前缀和恢复数组并计算最小值。不能边改边还原 —— 那样后面的修改会作用在已经被改过的值上，答案就错了。

07例题三 P1496 火烧赤壁（离散化 + 差分）

题目在说什么

数轴上有 n 个区间，每个区间是左闭右开的形式 [a, b)，也就是包含 a 但不包含 b。问这些区间并在一起，总长度是多少。区间之间重叠的部分只算一次。

数据范围：1 ≤ n ≤ 2×10⁴，−2³¹ ≤ a < b < 2³¹。坐标的取值范围从负二十多亿到正二十多亿，跨度几十亿。这种范围，开数组是绝对不可能的。这里有两个难点叠在一起：坐标太大，而且区间会重叠。

用哪个工具

坐标太大 → 离散化。重叠计数 → 差分。两个一起用。

数学模型

先把所有区间的端点收集起来，排序去重，得到一串坐标 x0 < x1 < ⋯ < xm−1。相邻两个坐标之间形成一段「基本区间」[xi, xi+1)，它的长度就是 xi+1 − xi。

并集总长度等于所有「被覆盖次数大于 0」的基本区间长度之和：

L = Σi = 0m−2 [ coveri > 0 ] · ( xi+1 − xi )

其中 coveri 表示第 i 段基本区间被多少个原始区间覆盖过。方括号是「指示函数」：条件成立取 1，不成立取 0。

解题思路

  1. 收集端点：把所有区间的左右端点都存进 coord，排序去重。这样就把几十亿的坐标范围，映射成了 0 到 2n−1 的紧凑下标。
  2. 差分标记：对每个原区间 [l, r)，用 lower_bound 找出它在离散数组里的下标 L 和 R，然后执行 d[L]++ 和 d[R]−−。
  3. 前缀累加：对差分数组求前缀和，得到每一段基本区间的真实覆盖次数 cover。只要 cover > 0，就把真实坐标差 coord[i+1] - coord[i] 累加进答案。
  4. 总复杂度：时间 O(n log n)，空间 O(n)。

核心代码

P1496 · 核心代码
for (auto [l, r] : seg) {                       // 遍历每个区间 [l, r)
    int L = lower_bound(coord.begin(), coord.end(), l) - coord.begin();   // 左端点的下标
    int R = lower_bound(coord.begin(), coord.end(), r) - coord.begin();   // 右端点的下标
    d[L]++;                                     // 从 L 段开始，多覆盖 1 次
    d[R]--;                                     // 到 R 段结束，撤销这 1 次
}

long long ans = 0;                              // 答案：并集总长度
int cover = 0;                                  // 当前被覆盖的次数
for (int i = 0; i + 1 < m; i++) {               // 枚举每一段基本区间
    cover += d[i];                              // 前缀累加，得到第 i 段的覆盖次数
    if (cover > 0) {                            // 这一段确实被盖住了
        ans += coord[i + 1] - coord[i];         // 加上这一段的真实长度
    }
}

完整代码

P1496 · 完整代码
#include <bits/stdc++.h>                        // 万能头文件
using namespace std;                            // 省去 std::
using ll = long long;                           // long long 的短名字

int main() {                                    // 主函数
    ios::sync_with_stdio(false);                // 关同步，加速读入
    cin.tie(nullptr);                           // 解绑定，加速读入

    int n;                                      // 区间个数
    cin >> n;                                   // 读入 n
    vector<pair<ll, ll>> seg(n);                // 存所有区间，每个是一对 (l, r)
    vector<ll> coord;                           // 存放所有端点坐标
    coord.reserve(2 * n);                       // 预分配容量，避免反复扩容

    for (int i = 0; i < n; i++) {               // 读入 n 个区间
        ll l, r;                                // 当前区间的左右端点
        cin >> l >> r;                           // 读入 l, r
        seg[i] = {l, r};                        // 存进 seg
        coord.push_back(l);                     // 左端点收集进 coord
        coord.push_back(r);                     // 右端点收集进 coord
    }

    sort(coord.begin(), coord.end());                       // 端点从小到大排序
    coord.erase(unique(coord.begin(), coord.end()), coord.end());   // 去重，得到严格递增的坐标表

    int m = (int)coord.size();                  // 去重后一共有 m 个不同坐标
    vector<int> d(m + 1, 0);                    // 差分数组，多开 1 个防越界

    for (auto [l, r] : seg) {                   // 把每个区间转成两次差分操作
        int L = lower_bound(coord.begin(), coord.end(), l) - coord.begin();   // 左端点下标
        int R = lower_bound(coord.begin(), coord.end(), r) - coord.begin();   // 右端点下标
        d[L]++;                                 // 从 L 开始覆盖 +1
        d[R]--;                                 // 到 R 撤销覆盖 -1
    }

    ll ans = 0;                                 // 答案：并集总长度
    int cover = 0;                              // 当前覆盖次数
    for (int i = 0; i + 1 < m; i++) {           // 枚举每一段基本区间 [x_i, x_{i+1})
        cover += d[i];                          // 前缀累加得到第 i 段的覆盖次数
        if (cover > 0) {                        // 这一段被盖住了
            // 计算 i 右边一段
            ans += coord[i + 1] - coord[i];      // 累加真实长度，不是下标之差
        }
    }

    cout << ans << "\n";                        // 输出总长度
    return 0;                                   // 正常结束
}

顺带说清 reserve / resize / vector(2n)

PDF 第 7 页专门用一段讲了这三个东西的区别，因为初学者特别容易混：

写法分配了什么大小 Size能不能直接下标赋值
reserve(2*n) 只分配容量（Capacity） 0，里面还是空的 不能，必须配 push_back
resize(2*n) 分配空间并填默认值 2n 能，但之后再 push_back 会追加在这 2n 个 0 后面
vector<int> coord(2*n) 同上，是构造函数的写法 2n，全部是 0 能，但同样会把数组「撑」成 2n 个位置

一句话区分：reserve 只是把房子盖好，里面没人；resize 盖好房子还塞进 2n 个人（值是 0）；vector(2*n) 和 resize 是一回事，只是换了种写法。

本题要往 coord 里 push_back 端点，所以用 reserve 预分配是对的。如果写成 resize(2*n)，最后数组里会多出 2n 个 0，坐标表就全乱了。

本题坑点

核心坑点：离散化压缩的只是「坐标下标」，不是「实际长度」。统计答案的时候，累加的一定是真实坐标差 coord[i+1] - coord[i]，而不是下标差 (i+1) - i = 1。这两者看起来都像「差」，但一个是几十亿，一个是 1，混了就直接零分。

建前缀和s[i] = s[i-1] + a[i]，s[0] = 0O(n)

数组从 0 开始存从 1 开始存，把 a[0] 或 s[0] 留成 0
前缀和用 int改成 long long，累加很容易溢出
差分数组开 n开 n + 2，因为要访问 d[r+1]
边改边还原所有修改做完，最后统一求一次前缀和
