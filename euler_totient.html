欧拉函数 φ(n)

在 1 到 n 之间，有多少个整数与 n 互质？ 每一个点，都是一次回答。素数把答案留在了最上方，合数则让图像长出细密的纹理。

Definition
φ(n) = n · ∏p | n (1 − 1/p)

p 取遍 n 的所有不同质因数；φ(1) = 1。

02 / ENVELOPE

素数构成上包络

当 p 为素数时，φ(p) = p − 1，所以素数点紧贴 y = n 这条线。

03 / COLOR

颜色表示互质密度

越接近金色，φ(n)/n 越接近 1，意味着 n 的质因数越少；青色的点则更“复合”。
